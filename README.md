# FreshMart Demand Forecasting System
A business analytics project to support procurement planning for perishable vegetables at FreshMart.

## Project Purpose
The project develops a demand forecasting and decision-support system for FreshMart's flagship store. The system will provide per-item demand forecasts, a 95% prediction interval, and a suggested procurement range before each replenishment cycle.
The procurement manager remains responsible for the final order decision.

## Project Scope
The pilot focuses on high-volume vegetables at FreshMart's flagship store. The project covers data preparation, demand analysis, forecasting, procurement-range development, dashboard reporting, and model evaluation.
Automated ordering, inventory optimization, and expansion to additional stores are outside the pilot scope.
